# 0.4.1：周期卡顿、漏绳、生成蘑菇、背包定位

## 本次实证

0.4.0 的用户测试确认反重力炮呈现有效，但存在约每秒一顿、绳索缺失、生成蘑菇缺失和包内物品抖动。以下证据来自本机日志、只读私人片段聚合与本机原生实现，未上传或改写日志/录像。

1. 两次日志在开始采集时报“绳索实体达到 256 个上限”。最新约 71.15 秒 Schema 6 片段的 256 个绳索族实体**全部是静态 vine**；首帧 249 个不可见/失活，来自未激活关卡，7 个可见为原场景桥。整段没有实际发射 rope、anchor 或 hook 数据。不是有绳形但没选对颜色，而是注册时就被静态地图对象占满了。
2. 日志中多个效果报 `sprite is null`。原复制代码对 Grid/未使用贴图页也调用 `AddSprite(null)`，整个粒子组构建失败；失败后每秒重复创建。加上特效采集/回放每秒扫描全部已加载粒子及层级、音频周期扫描所有者，这些是确定存在的周期工作源。没有取得当时 F9 耗时，不能把卡顿的全部时间占比归因于其中某一个。
3. 弹跳蘑菇的投掷物是 `Item`；落地后由原生 `ShelfShroom.Break` 生成的 `BounceShroomSpawn` 没有 `Item`。Schema 6 能找到投掷物，却无成品生成物数据。
4. 原生 `Item.SetState(InBackpack)` 会清空手持者，包内展示由 `backpackSlots[slot]` 定位。旧回放读取手持者字段，再插值物品世界姿态，未将物品绑定到回放角色的包内槽位。

## 已改策略

### 周期工作

- 特效只在场景初始化建立全目录，其后由角色/物品出生、原生使用与网络生成通知维护。回放资源目录也只在进入时建立，不每秒重扫；不恢复反重力炮的玩法逻辑。
- Grid/关闭贴图页的空 sprite 占位不调用 AddSprite；Sprites 模式只复制有效资源。仍不兼容的效果按资源隔离，在本次播放中不反复创建；上限有界，重新进入播放才重试。
- 音频只做一次原生所有者初始发现，后续使用原生生命周期/播放事件登记；不再每 0.1 秒搜索一个所有者类型，也不因缺失 clip 每两秒重扫资源。小型原生 SFX 池与已登记音源状态仍正常检查。
- 绳索取消每秒四类全场扫描；一次初始化后靠已核实出生/附着事件维护，第三方漏事件兜底为稀疏分帧遍历，不能承诺第三方自定义生成立即发现。
- 原有特效分帧预滚预算保留。首次资源载入/模型创建、GPU 和全部其他 Mod 的耗时仍要游戏内测量，代码及单元测试不证明帧率已完全恢复。

### 绳索

- 原地图的固定藤索/桥面不占动态录像名额，保留原场景呈现。只录实际动态 Rope、Hook、发射 Anchor 与生成的 SpawnedVine。
- 保留真实碰撞形成的分段、视觉骨骼、宽度与附着，不猜首尾直线。资源路径已按本机 ResourceManager 复核；动态横索使用真实点计算裁剪包围盒。
- 旧 Schema 6 若已被上限漏录，不可能恢复真实绳形。修复后的新片段才能验收发射绳与锚定过程。

### 生成蘑菇：Schema 7

- 新增 `Spawned` 独立数组，支持明确核实的弹跳蘑菇与平台蘑菇；起点完整、后续差分，包含实际姿态和可见性，删除显式记录。
- 本地及远端出生从 `PhotonCleanupHelper.OnPhotonInstantiate` 观察，销毁独立处理。出生/原生弹跳事件后的短窗口保存真实节点动画结果，静止时共享状态；不调用生成、碰撞或伤害脚本。
- 本机某个弹跳成品的 `bounceAnimator` 实际为 null；不为它伪造不存在的动画。治疗蘑菇无成品网格，其出生通知转入特效观察；并非所有地形机关已实现通用回放。
- 新文件 Schema 7，读取兼容 Schema 2–6。旧录像未采集的生成物不会猜测补回。

### 背包

- 根据玩家当前库存中的真实实例 GUID、物品 ID 与槽号找到唯一包内插槽；无需重录即可利用旧录像已有的库存数据修正绑定。
- 使用原生 slot 的局部姿态与半 COM 偏移，包内物品随背包整体移动；不使用物品世界轨迹的摆动去定位它。
- 先更新角色，再更新附着物品。手持/落地/收回/转交边界不跨坐标空间插值；换包与骸骨/蘑菇变身保留原生插槽层级。
- 未知库存、归属冲突、地上容器不猜绑定，保留记录的原姿态。其他 Mod 动态修改物品 COM 尚未另存，仍可能需要进一步适配。

## 验证

- 全量 Release `-t:Rebuild -warnaserror` 编译通过，0 警告、0 错误；241 项协议/策略测试与 19 项视角契约测试通过。包含空 sprite 决策、不再周期重建失败资源、静态藤索准入、包内精确绑定与状态边界、Schema 7 增量/裁剪/删除/预算等；视角测试使用替身，不是 Unity 实机验证。
- 真实旧 Schema 6 片段只读兼容核验。反重力球轨道保留，不更改原录像。
- 本次未控制或关闭运行中的游戏。不能以编译/纯逻辑测试代替“每秒卡顿已消失”、绳索可见、蘑菇时序和包内稳定的实机验收。

建议测试：新录一次绳枪发射并固定、放置弹跳/平台蘑菇、往背包放物品后走跳，按 F6 保存；回放先停在包内状态，再反复拖动收拿/发射/生成前后。按 F9 分别记录采集与回放 CPU 指标，对照此次周期扫描的变化。
