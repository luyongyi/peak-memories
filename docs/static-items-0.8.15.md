# 0.8.15 静态物品短暂消失修复

## 根因与处理

用户确认脆梅表现为物品短暂消失后出现。检查实际播放路径发现，物品在原生外观或灯光恢复尚未取得本帧额度时，无条件隐藏已展示的副本。即使静物内容相同，读入新页得到不同的快照引用也会触发该路径。放置物、互动实体和非简化生物模型有相同的隐藏行为。

修复在连续播放时保留已经完成的呈现；初次创建、跳转、休眠、复用、失活和错误仍保持正确隐藏。跳转的外观/灯光重置跨帧保留，只有对应步骤实际收到重置时才清除标记，姿态缓存同时失效。

待处理状态独立于缺失对象计数和静态数组快速路径。分帧恢复可能先完成旧目标 A，再开始最新目标 B：完成的状态仍可呈现和推进姿态，同时保留下一帧更新请求，避免暂停后漏更新或连续变化的大模型永远等不到显示。

物品、放置物、互动实体的 Playback 类从采集文件拆出，便于直接编译生产调度做测试。采集频率、事件休眠、数据格式、预算上限及共享块/独立页读取机制未改变。

## 检查与实机对照

Release 解决方案按警告视为错误构建通过，0 警告、0 错误。全部 1226 项合约检查通过，包含新增 ItemPlaybackContract 19 项和 StaticPlaybackContract 36 项。新增测试使用真实播放调度、预算、对象池，边界组件使用明确的 Unity 替身；覆盖预算延期、首次构建、连续跳转、暂停续作、同/异 key 池复用、失活、异常、恢复，以及持续变化时不饿死。

实际游戏以相同的完整录像副本测试 0.8.14 与 0.8.15，分别从 9.5、132.8、142.3、351.4 秒播放约 8 秒。跳转后先等待稳定，随后在每个渲染帧观察录像标记为活动的物品根节点；未首次显示的初始加载不计为闪烁。未人为耗尽预算或修改录像状态。

测试包含正常按页播放和多个远近跳转；这是可见性正确性诊断，不据此宣称帧率提升或长期性能已经量化。固定互动对象和生物调度还由独立合约验证，未将它们的替身测试冒充全部原生资产实机验收。

## 安装与数据评估

最终实机测试 DLL 版本 0.8.15.0，SHA256：`6D7F564592EF5451EE4FCD88B6DCA340DF794FB3F66525AEA2605FBDAA9676EC`。已安装到游戏，0.8.14 另行备份；最终源码构建与已测试、已安装 DLL 哈希一致。临时测试插件已移除，游戏正常退出，原录像和快速存档校验值未变，配置值不变，仅自动生成的插件版本注释更新。

本次最新完整录像为 382.07 秒、37,061,247 字节，实际平均约 5.82 MB/分钟（十进制 MB）。数据分析只读原文件，体积优化尚未改变本次生产采集路径。

精确物理占用：主帧页 33,540,905 字节（90.50%）、特效跳转历史 1,497,303 字节（4.04%）、共享块 1,758,267 字节（4.74%）、头部/索引/尾部 264,772 字节（0.71%）。语义类别在一个压缩成员里共同压缩，不能精确拆开最终 deflate 字节；本地报告按各类单独压缩的权重分摊实际成员大小，明确作为估计，不能把某类占比直接当成删除它会节省的比例。

主要热点是玩家骨骼、远处仍活动的童军长骨骼，以及 200 个静态孢子地雷在每页重复保存的基线。孢子地雷完整记录为 398–431 字节，全部低于当前 512 字节的整对象共享门槛；逐对象跨 386 页字节一致，仍重复内联。下一步可以针对高重复的小记录启用共享，保留每页独立引用和直接跳转。远离玩家的生物需要区分动作发生与闲置状态，再评估骨骼采集唤醒策略，不能统一删除生物动作。

完整本地证据位于 `local/checks/static-items-0.8.15/`：`session/visibility-comparison.json` 保存实机观测，`session/cleanup.json` 保存恢复与 DLL 校验；`storage/storage-analysis.json` 保存按类数据及统计方法。原始私人录像与诊断输出不提交到仓库。
