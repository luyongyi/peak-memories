# 0.8.31 静息采集、共享目录与原生验证

本版继续把重复数据和重建工作转移到后台存储与回放端。Schema 26／完整录像容器 v4；旧录像读取保留。1 GiB 按需解码缓存、独立跳转页、共享目录数量和页面展开预算未增加。

## 采集与回放修改

- 乌鸦已核验的待机、惊飞记录原生动画引用与时间锚。没有分配语音目标时，重型 Animator／根节点安全检查错峰到约 0.75–1 秒；Assign、FlyAway、语音状态和显隐边界即时唤醒，并保留有限的后续确认。分配目标、真实嘴型混合、过渡和未知控制器继续使用真实姿态回退，常规昂贵读取仍为 5 Hz。
- 青蛙原生 `inWater` 也会在 Map 射线命中普通地面时置位。现在检查游戏已缓存命中的实际 Water 标签，不重复射线检测。真实水中漂浮、吐舌、拉拽、跳跃、持有与烹饪仍采样；新增分原因拒绝计数，便于区分真正活动与保守回退。
- 已核验的地面 EarlyWorm 原生动画可继续由回放求值。物理根和速度稳定时复用末态，不因视觉时钟推进重复写观察时间；已有低频安全检查负责根运动。拿起、状态变化和真实新事件恢复采样，唤醒包切断旧静息区间的插值。
- 水豚仅在已审计的无 Animator／无刚体、Wobble 未启用等组合下静息；食人花仅在游戏自身已经禁用已核验 Animator、没有目标／咀嚼／过渡且尾段结束时静息。食人花启用中的 1.5 秒 Idle 有十个动态 streamed 通道，继续采集实际姿态；不能把空 `m_FloatCurves` 误认为没有动画。咬人／松口事件保留有限 1 秒细节尾段，覆盖原生 0.5 秒回正。
- 静息策略缓存组件目录，安全细查错峰执行，契约验证每分钟不超过约 81 次；不会每个场景帧扫描层级、读取完整骨骼或更新材质。启用中的食人花和未知资源提前回退，不为无法进入的静息策略重复读取根节点。静息提交以成功的末态快照为前提，失败重试不授权复用旧状态。

原生动画仅在惰性视觉副本上求值。声音、羽毛、孢子爆炸、烹饪变化等继续由独立声音／特效／状态轨负责，静息不删除回放对象。玩家采样与队友网络模型策略不变。

## 后台共享协议

已审计原生动画实体在完整基线写入时，先拆出不变 Nodes／Visuals，再处理观察时间和动画锚点；纯相位校准不再被提升成新的乌鸦整实体共享块。

新增 kind 9 为较大身份顺序叶，kind 10 为完整静态生物目录。目录至少 256 项才启用；排序至少 256 个身份或总身份字符数至少 8192 才共享。目录只包含符合静态规则的完整 DTO，不允许嵌套共享引用，解码在动态更新前种入本页状态并校验完整顺序。超预算或共享表满时回退为页内完整数据。

Schema 26 可省略已知为空的 updates／removals／order 数组；旧 schema 的严格字段要求保留。类型、未来引用、重复身份、顺序全排列、轨道数量、原始页／解码页预算继续校验。共享模板仍最多 128 项／8 MiB，文件共享块仍最多 32768 项。哈希、JSON、压缩和目录构建均在后台写入线程，不增加 Unity 主线程逐对象序列化。

## 失败候选与修复

首次原生候选 A 完成了 379 次姿态对照，零几何失败，但回放打开失败，未验收。新静态目录直接取原生对象时，误将原生绝对观察时间／动画锚点写入已归零的录像；15 个页面出现未来观察。修复为统一从后台重定位后的帧构建目录，保留严格时间验证。新增原生起点 120 秒、384 陷阱／72 待机蜘蛛／活动蜘蛛／真实特效出生的分页写入、倒序读回、目录原始锚点、独立历史和源对象不可变回归。

A 的乌鸦最大生产时钟误差约 2.415 ms，超过此前每次观察即纠偏的 2 ms 验收假设。新事件／安全检查间隔下，2 ms 是检查时的纠偏阈值，不能声称连续误差永远低于它。复测明确记录安全检查之间的误差，采用 10 ms 子帧预算；精确相位的骨骼／形变／材质和源对象不可变 oracle 保持原有严格容差，并新增强制要求真实惊飞状态通过。

升级版本会让 BepInEx 在保护探针启动前重写模组配置的注释版本头。测试退出后仅在所有非注释设置一致时恢复原始文件并重新核对哈希；实际设置不同则保留失败证据，不覆盖。

## 验证范围

Release 构建要求零警告；协议 1265 项及 41 组独立测试通过，包含新静息边界、非零起点目录、纯静态无 order 页、旧格式、动作时钟和有界缓存检查。合成契约不模拟 Unity 渲染或证明 FPS。

所有失败候选保留在本机，不覆盖原录像。全游戏全部关卡变体、所有生物行为和多人玩法尚未穷尽，`CoverageComplete=false`。5 Hz 未知运动中间姿态仍是回放插值近似；不会将未触发行为或一次短路线声称为全覆盖。
