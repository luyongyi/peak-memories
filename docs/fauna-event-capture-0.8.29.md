# 0.8.29 青蛙与乌鸦状态采集

本轮处理青蛙物品身体、青蛙舌头与乌鸦的重复采集。原版 PEAK 资源留在本机；录像只保存资源标识、原生动画时钟、状态检查点及真实变化。未知控制器和未核验的动作继续原采样路径。

## 采集策略

| 对象／状态 | 记录与主线程工作 |
|---|---|
| 青蛙：地面静置且原生 FrogIdle | 完整检查点及原生相位；进入原有休眠工作集，约每 0.5–0.68 秒错峰验证根位置、速度和待机时钟，不遍历骨骼／材质 |
| 青蛙：原生隐藏休眠 | 保留隐藏末态；同样以原有安全检查和事件唤醒 |
| 青蛙：水流、拿取、投掷、吐舌、拉拽、跳跃或未知动作 | 最高 30 Hz 真实姿态采样；不凭 `Mob.sleeping` 单独判定停止 |
| 青蛙舌头：闭合 | 初态及最终收回状态；缓存字段和显隐检查，不读取整条点数组 |
| 青蛙舌头：吐出、拉拽或显隐／几何边界 | 恢复现有采样，保存短动作及最终末态 |
| 乌鸦：已核验待机／飞离且嘴层权重为 0 | 完整检查点＋原生 clip 相位、速度；稳定后在骨骼／外观读取前跳过，并复用原数组 |
| 乌鸦：嘴层非零、过渡、未知资源／状态 | 完整骨骼回退，保留语音嘴型 |

原生 Reposition、Attack、HopAway、LetGo、碰撞与物品事件唤醒青蛙；乌鸦分配、偷声切换、随机相位重置和飞离事件使时钟重新核对。缺少所需事件钩子时退回完整采样。缓存已有组件和字段，不新增生产环境场景扫描。稳定乌鸦仍核对原生 Animator 状态；停止全树采样不等于没有 Unity 属性读取。

## 回放与存储

原生动画只采样到不含 AI、网络、物理、SFX 和粒子脚本的视觉副本。声音与羽毛继续由独立音频／特效事件轨复现。飞离锚取自真正开始播放的原生 Animator 状态，处理原生协程晚一帧启动的间隔。

Schema 24 增加物品待机动画描述符并扩展生物的已核验 clip 标识；容器仍为 v4，继续读取已有 Schema 10–23。页面保留独立完整初态，动画按绝对录像时间求值，支持暂停、倒跳及冷页面跳转。完整录像和精彩片段都重定位动画锚；源状态保持不可变。回放解码仍按需载入，上限 1 GiB。

## 验证口径

纯协议及缓存回归 1,229 项通过；本轮相关运行时契约还包含青蛙 15 项、物品采集 18 项、物品回放 25 项、乌鸦 9 项、静态回放 52 项、原生事件 61 项、舌头边界 7 项及共享预算 10 项。生产解决方案 Release 构建零警告、零错误。合成契约不替代 Unity 原生画面对照。

原生视觉对照与性能测量分开运行：视觉探针使用正式 `VisualReplica` 和动画运行时，逐节点比对同一 `LateUpdate` 的位置、旋转、缩放、显隐与世界根坐标，并检查原生源对象未被写入。开启视觉探针的运行不得用于性能结论。

主线程耗时是实际接受录像帧的采集调用时间，不是游戏 FPS；文件增长使用完整封盘和至少 100 秒雾沼稳态窗口。家族／模块百分比为实际 UTF-8 字段压缩前占比，不能当作压缩后模块占比。分别运行的原生物理、声音和事件时序可能不同。

本轮未改 EarlyWorm 的活动外观采集，也未将真实语音嘴型改成纯事件；剩余占用需按实测继续评估。有限路线验证不代表全部地图、全部攻击与多人语音已完整验收。
