# 0.3.1 性能策略与验收

## 原问题的证据

本机 0.3.0 最新 Schema 3 片段有 3628 帧 / 62.253 秒，首帧 171 个物品、132 个箱子，合计 6517 个视觉节点。该片段平均采样率约 58.26 Hz；这不是游戏 FPS。日志发现 742 段 `LuggagePlayback.SampleAnimation` 调用栈及 6450 条 FreeCAM 主相机重试警告。没有 Unity Profiler 数据，不能把某个项目武断地认定为唯一瓶颈。

0.3.0 的合成内存基准只有 256 个物品节点，未运行 Unity Transform、Animator、渲染和日志路径。因此不能用它承诺游戏帧率。

## 本次实现

| 分类 | 采集 | 回放 |
| --- | --- | --- |
| 人物/握持 | 60 Hz 目标，基础动画层复用列表，六个握持骨骼缓存 | 动画归并复用容器，平滑播放仅恢复手工覆盖骨骼；跳转或动画集合变化时完整重置 |
| 静止物品 | 一份基线；生命周期、使用/状态事件标脏，0.45～0.626 秒错峰根检查兜底 | 相同状态版本不写 Transform；只移动根而子树不变时不写子树 |
| 持物/移动例外 | 附着、真实移动和 MobItem 活物保留高频姿态 | 逐渲染帧插值；没有重新运行物理或使用逻辑 |
| 库存/装扮 | 库存事件/选择变化立即检查，2 Hz 兜底；身份和未变外观共享 | 装备变化时更新背包 Renderer；UI 10 Hz 缓存，seek/切人立即刷新 |
| 箱子 | 原生动作事件＋clip/time/rate 锚点；初始/离散变化基线 | controller-free Animator + manual PlayableGraph；禁用动画事件，终态停止求值；出错隔离而非不断重试 |
| 地图/昼夜 | 场景引用缓存，关卡变化立即检查，世界状态 10 Hz | 地图开关/光照按变化应用，避免两处重复驱动 |
| 缓存/文件 | 不可变对象/数组共享验证与引用计数 | F6 先冻结有界引用数组，后台裁剪、重算时间锚点并写入 |

箱子开启锚点可能早于窗口起点：保存时允许负锚点，确保两分钟前已打开的箱子在首帧就是打开状态。事件本身不能替代起点快照。Schema 4 不要求覆盖旧录像，继续只读支持 Schema 2/3。

模型副本不调用原开箱、复活、消耗、网络 RPC 或随机生成函数。掉落用当时真实记录的实例和位置还原。没有引入常驻磁盘录像，仍只有 F6 写片段。

回放期只针对核实的 FreeCAM 0.0.2 manager 保存并暂停 enabled，退出恢复；不永久关闭其他 Mod。原生角色/光照更新保护只在场景加载完成后的 Presenting 阶段生效，不拦截 Photon 或对象生命周期。

## 实机验收（待用户运行）

1. 保持旧 PeakTrailRecorder 和其他设置不变；正常游玩分别观察静止、移动、开箱、切换装备与丢出物品。
2. F9 查看采集主线程 avg / p95 / max 和平均分配；日志 `Replay performance` 分 Actors、Items、Crates、World、Validate、Buffer。p95 取最近 256 次，avg/max 为本次进程累计。不要把采样 Hz 当 FPS。
3. F6 保存一次，确认不中断采集；回到回忆录播放，验证开扣/开盖、掉落、背包与手持。前后拖动、暂停于开箱中途、2x/0.25x 都应对应同一时刻。
4. 回放中按 F9 记录 Playback 计时。检查不存在 `Non-Legacy animations cannot be sampled` 洪水、FreeCAM 逐帧 retry；退出后确认原 FreeCAM 状态恢复、正常游戏可进入。
5. 专门测试一个已打开箱子在 120 秒以前开启的片段、队友开启箱子、出生/销毁物品与关卡切换。

计时范围是插件主线程工作，不包含 GPU、不覆盖原游戏所有 Update；首次进入回放创建模型和显卡 draw calls 仍需真实场景 profiling。当前没有把所有物品实例做分帧预热，也没有通用全场景 LOD/完整粒子重播；它们是后续依据实测决定的优化，不是本版已完成项。

## 自动验证边界

Release 构建以警告为错误；纯数据测试覆盖锚点推进/终态/裁剪、Schema 2/3/4、对象增量/删除、120 秒淘汰、快照并行安全、静态采样策略和动画归并。ReplayView 测试使用内存替身，不是 Unity 场景或画面测试。需实机验收后才能给出帧率改进数字。

2026-09-25 本地验证：Release 构建零警告/错误；142 项数据/策略检查与 19 项 ReplayView 检查通过。原有 Schema 3 的 62.25 秒、3628 帧私人录像只读加载成功，未转换或覆盖。游戏关闭时已备份并安装 0.3.1.0；DLL SHA-256 为 `A523950DF90FF31C1D6C75F7CD55E9235354FCD76350BBE3D6244BED2D257F84`，旧足迹 DLL 和配置哈希保持不变。此结果不代表已经完成新版 Unity 实机性能验收。
