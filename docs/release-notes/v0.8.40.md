电影模式、游离镜头与普通回放合编为一个 `PeakReplayLab.dll`。电影源码在 `modules/PeakReplayCinema` 独立维护，录制和采集不依赖该模块。

- 回放按 C 切换游离镜头，右键＋WASD/QE 飞行，Shift 加速、Ctrl 微调；修正第三人称滚轮单位，每格缩放 2.5 米。
- F8 打开电影编辑器，支持推拉、横移、环绕、升空、关键帧、FOV、景深与调色；H 切换纯画面。
- 关键帧可点选、拖动、按秒移动或复制，支持 XYZ、角度、视野和对焦距离的精确输入。
- 最多 64 步撤销／重做，方案列表、新建、复制和重命名；每 10 秒写入独立恢复副本，未保存退出、加载和新建提供保存／放弃／取消。
- 读取期间时间条保持请求位置，生成预设后正确显示过渡类型，取消跳转会丢弃旧机位请求。

下载 `PeakReplayLab-0.8.40.zip`，退出 PEAK 后将其中的 `PeakReplayLab.dll` 放入 `BepInEx/plugins/`，保留已有配置、录像和其他插件。需要已安装 PEAK 和 BepInEx 5。附件包含构建清单及 SHA256 校验，不含游戏资源、测试插件或私人录像。

开发候选已完成 1280×720／Direct3D12 短录像验收：运镜、六页编辑器、精确机位、撤销重做、保存保护、自动恢复、方案管理及退出恢复。数值输入和确认框另做鼠标实测，时间轴指针及快捷键使用游戏输入注入验证。原录像、存档、配置内容摘要不变。十二组发布合同测试、独立上传缓存检查与发布验证器由本机和 GitHub Actions 复核。

移动／复制关键帧要求已读取且同一关卡；画幅目前为构图参考。持续跟拍、画面参数动画、内置视频导出属于后续阶段。短验收不代表所有显卡、分辨率、跨关卡长录像的完整性能验收。
