# 回忆录 0.7.2 性能验收报告

验收日期：2026-10-07（Asia/Shanghai）。本次修复针对正常游玩时持续录制掉帧。主采样一直为最高 60 Hz，受真实渲染帧率限制，不补采样；用户最新 0.7.1 录像 676 帧／16.7117 秒，实际采样 40.3908 Hz。这个数描述录像采样，不能替代完整游戏 FPS 或 1% low。

结论：代码与离线数据验收通过，0.7.2 已安装；真实游戏平均 FPS、1% low、0.1% low 和整体采集 2／4 ms 目标待实机验收。

## 已修复行为

0.7.1 在队列写空后删除共享对象计量图，下一次入队在游戏主线程重新遍历。0.7.2 保留最新成功入队帧的计量基线，所有保留字节继续计入原 128 MiB，待写帧数仍最多 360。基线不是待写帧，空队列显示非零保留字节属于缓存；完成或故障排空后基线归零。超限时先回收旧基线再尝试一次，不能回收真实排队／写入中的帧。

静态地雷爆炸事件现在会让已登记条目变脏，下一次主采样立即记录消失；普通根变换和 activeSelf 改为 1–1.5 秒错峰核查。未激活生物保留基线，活动变化立即刷新，活动骨骼最高 30 Hz。物品根运动维持原频率，材质独立 0.5–0.75 秒截止，原生变更通知、颜色、烹饪、点亮绕过截止；只给有实际动态视觉资格的对象读取 30 Hz 动态 shader 属性。动态灯保持源采样率，无灯对象复用空状态。

环境连续状态 20 Hz，离散事件按主采样观察。新增明确观察时钟；即使环境值不变也保留真实观察锚，防止静止之后的运动被提前插值。新格式 Schema 13 向后读兼容 Schema 10／11／12，旧 Mod 不读新版录像。环境回放索引在后台与关节索引一起建立，保持 64 页／256 MiB 原缓存上限，包含跨页、回拖、未知状态、切段和长断帧处理。

## 实机性能验收范围

整次采集平均 ≤2 ms、P95 ≤4 ms 是目标，**尚未用真实 Unity 游玩确认**。游戏平均 FPS、1% low、0.1% low 也尚未实测，本报告不判为达标。

新版诊断报告保存在 `BepInEx/PeakReplayLab/Performance/`。CPU 阶段包括 Capture、Enqueue、Appearance、Lights、StaticTraps、DynamicCreatures、Environment、Discovery 等；P95／P99 取最近 256 次，最大值及平均值自当前采集开始累计。阶段嵌套，不能直接相加。GC 次数属于整个进程，不能全部归因于回忆录。

帧时间使用实际 `Time.unscaledDeltaTime`，独立于录像的最高 60 Hz 时钟。录制开／关各保留最近 8192 个符合条件的渲染帧；排除主菜单、回放、封存及每次切换后的 2 秒暖机。1%／0.1% low 定义为最慢 ceil(N×比例) 帧平均耗时的倒数，至少需要 100／1000 帧；不足时输出 null。首次启动的尖峰仍会留在 CPU 最大值中。

建议在同一关卡、同一位置和镜头录制 60 秒；按 F4 停止并等待封存结束，在同位置再停留 60 秒，按 F9 保存包含两组帧数据的报告。重复对照并检查地雷爆炸消失、风向切换、熔岩运动、暂停及跨页回拖。比较记录时应保留场景、样本数、两组帧时间及 GC 信息，不能仅比较两个平均 FPS。
