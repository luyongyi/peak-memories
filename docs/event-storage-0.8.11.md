# 0.8.11 静态物品事件驱动与跨页去重

本轮完成代码、候选 DLL 和离线验证，未将 Mod 装回游戏，未改写原录像。记录日期：2026-10-11。

## 采集行为

物品首次进入目录时建立基线。已核查的普通固定静物，在没有持有者、活动视觉或待完成的物理通知时进入事件休眠。拿取、投掷、受力、位置重置、网络同步、烹饪及状态变化会合并入唤醒队列；事件回调不立即重扫模型和材质。

物品发生移动或曾被持有后，持续记录运动；远离所有录制玩家并连续静止至少一秒，才保存最终状态并重新休眠。物理事件后保留至少 0.25 秒观察窗口，防止下一次物理更新尚未应用就停采。网络模拟归属不等于实际持有者，丢下后的运动仍被采集。

主线程采样只遍历活动集合；休眠物品每帧最多轮转 32 个，使用缓存坐标检查距离。普通休眠刚体和未知组件保留错峰检查。生命周期增量维护物品目录，移除正常情况下每两秒重建目录的工作；任一事件入口安装失败时，自动启用分批保底检查。

核查本机游戏 205 个 Item 及派生类资源，97 个属于纯事件休眠候选，仍需满足运行时固定刚体、没有持续视觉变化、事件入口健康等条件。生物、灯光、骨骼动画、黏附和未知定时行为继续采样。粒子与其他独立特效沿用自己的采集轨，不随普通物品休眠关闭。

## 存储与跳转

- 完整录像容器升级到 v3。跨页不变的完整对象快照只存一次，通过直接偏移引用。共享块不引用其他共享块，也不要求从录像开头或上一页重放。
- 维持约一秒独立页面、按需读取、1 GiB / 64 页解码缓存上限和独立特效历史。原有分帧构建预算未改变。
- 哈希、去重和压缩在后台写入线程执行。共享目录最多 32,768 项，满后新增状态写在页内，保留数据完整性。
- Schema 16 对对象节点的位置、旋转、缩放与显隐采用无损字段差分；路径、顺序或节点数改变时保存完整数组。未降低人物或物品采样频率，未新增精度量化。
- 读取临时缓冲只按需保留至多 3 MiB，不额外缓存历史解码对象，关闭回放时释放。该缓冲属于读取工作内存，与 1 GiB 页缓存分别计数。
- 新版继续读取 Schema 10–15 及完整录像 v1/v2；新版录制需要支持 Schema 16 / v3 的播放器。旧录像不会自动变小。

物品专项覆盖拿取、丢出、受力、初始固定物、延后物理更新、销毁、进入距离范围及事件失效降级。另核查真实游戏程序集的 48 个入口签名，全部通过；使用 HarmonyX 2.9 对受控对象实际安装全部 48 个生产补丁，验证调用顺序、返回值、异常隔离和卸载。

存储专项覆盖跨页消失/重现、同内容不同引用去重、随机前后跳转、物品动作、独立特效历史、旧格式、损坏数据、取消和并发缓冲隔离。节点差分检查历史快照不可变及浮点位精确恢复。

调度合成检查：1000 个休眠物品与 4 个活动物品，600 帧内活动遍历 2400 次，原全表方案需要 602400 次；额外 19200 次缓存距离检查，休眠物品原生读取 0 次。这是工作量计数，不是 Unity 主线程耗时。

## 真实录像抽样对照

原录像 1,551,309,244 字节，时长约 43 分钟。只读抽取从开始到结束的 18 页、977 个不同帧；旧实现和新实现都用同一 .NET 8 运行时重新写入新的抽样文件，再反向逐页及按固定随机序列读取。

| 指标 | 本轮修改前 | 最终候选 |
|---|---:|---:|
| 抽样文件字节 | 13,969,498 | 4,319,287 |
| 首次页解码中位数 | 148.42 ms | 130.51 ms |
| 首次页解码最大值 | 185.75 ms | 197.35 ms |
| 重复随机读取中位数 | 140.29 ms | 132.54 ms |
| 重复随机读取最大值 | 186.27 ms | 208.90 ms |
| 单页临时分配中位数 | 10,661,328 字节 | 11,076,548 字节 |

同一批数据体积减少约 69.1%；读取中位数没有变慢，但最大值仍有波动，临时分配比旧实现高约 3.9%。前一次最终候选测量还出现过 601 ms 的随机读取最大值，因此这些短时离线数据不足以证明尾延迟改善或卡顿已消除。报告保留此前结果，未以中位数掩盖长尾。

977 帧逐字段比较通过，物品、对象姿态和特效数据一致；独立特效历史比较通过，全部反向页和 24 次随机页读取通过。人物骨骼仍使用原编码器；旧数据重新编码会经过原有量化，比较前已用同一原编码器规范化预期人物关节，不能据此声称旧人物关节转码位级无损。

以上结果仅体现新存储格式的抽样收益。离线重写没有运行新的事件采集，不能衡量事件休眠的额外体积收益，也不能按 69.1% 直接推算整场新录制大小。

## 尚待实机验收

本轮遵照要求不安装候选 DLL，因此没有新增 Unity 画面、听感、完整玩法或游戏帧率结论。未知定时行为为避免漏掉短动作，节点采样较旧版远处慢速检查更积极，可能抵消部分静物节省的开销；整体主线程耗时仍需后续实测。

未被原生事件通知的外部 Mod 直接变化只能由保底检查发现，检查间隔内的变化不能补造。本版保留此前已明确的复现限制，没有声称所有游戏行为与特效百分之百覆盖。

保底检查的到期时间约为 0.5–0.676 秒，还需等待每帧最多 32 个对象的轮转；1024 个睡眠对象在 30 FPS 下完整轮转约需 1.07 秒。原生事件唤醒直接入队，不受该轮转等待影响。没有常规 Update、仅通过未知协程或 Tween 短暂改变子节点的外部行为仍可能漏采。活动物品产生新状态时也仍需重组包含静物引用的帧数组，主线程总工作并非完全只与活动物品数量有关。

原始日志、签名及资源审计、配对对照 JSON 位于 `local/checks/event-storage-20261011/`；对照采用 `paired-baseline/inspection.json` 与 `paired-final/inspection.json`，前一次最终候选结果位于 `final-inspection/inspection.json`。
