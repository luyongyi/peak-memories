# 0.8.21 原生待机回放与全生物逻辑审查

日期：2026-10-13。候选已构建，未安装进游戏。新录像 Schema 21；完整录像容器仍为 v4。

## 已实现

蜘蛛挂网停采后不再冻结腿部。进入已核验的原生 `SpiderIdle` 状态时，一次保存真实动画相位、有效速度、录像时间锚和蛛丝阶段，随后停止骨骼、材质和线点读取。回放只对无玩法脚本的视觉副本求值原生动画，再用原生 `RopeRender.DisplayRope` 公式从副本腹部重建蛛丝。不启动原生 Animator controller、AI、RPC、协程或物理。

采集准入检查真实状态、未眩晕、无过渡、单层单片段、权重、速度、更新时钟、原生资源和完整蛛丝模板。未通过则继续 30 Hz 实际采样，短暂过渡后有界重试。下落、抓捕、松手返网、受击及显隐事件立即恢复真实采样。蜘蛛未结束的返程不因为“松手”提前停止。

甲虫按游戏真实睡眠逻辑处理：原生睡眠会隐藏模型并关闭 Animator，因此保存隐藏末态后停止几何采样，醒来完整更新，不额外播放醒着的默认动作。童军长待命门控和静态孢子陷阱初态/消耗事件策略保留。

审查同时补齐 `GhostBall` 和 `PlayerGhost` 主体。两者使用固定原生资源、现有有界目录及最终姿态/外观记录；幽灵球按实际动画输出记录脸部贴图、透明度和着色参数，粒子仍在独立特效轨道。当前 shader 未声明的残留 `_Step` / `_CracksColor` 不被当作必然可见效果；HDR 数据仍保留来源语义。

## 主线程及跳转路径

停采期间只保留已有缓存状态边界检查，不查询 Animator 状态/片段，不遍历骨骼/材质或读取 40 个蛛丝点。Animator 查询集中在停采边界和有限重试；新幽灵身体通过出生/初始化/销毁进入已有目录，没有新增周期全场搜索。幽灵球动态贴图检查仅对该类型开启，普通静物没有新增周期纹理读取。

播放使用 `phase + (录像时间 - 时间锚) × 速度` 求当前循环位置；相位保存在当前页完整初态/共享块中，远跳、反向拖动和倍速无需从出生补跑。暂停重复求值复用已呈现状态；跳转、动作切换、检查点重写及视觉池复用会正确使缓存失效。蛛丝成功重建时只写一次 40 点，不先写旧点再覆盖一遍。

独立页面、按需读取、1 GiB 缓存和分帧构建预算沿用现有路径。动画/蛛丝绑定一次占用构建额度。回放所需原生资源缺失时显示现有缺失提示，不静默展示冻结姿态。
