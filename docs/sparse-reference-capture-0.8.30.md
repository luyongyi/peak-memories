# 0.8.30 低频观察与原生动画引用

本轮将采集工作向回放端转移：记录真实低频观察、动作边界和已核验的原生动画引用，由回放端按录像绝对时间求值。原版资源不写入录像，玩家骨骼和队友网络同步策略沿用原设置。

## 策略

| 对象／状态 | 采集 | 回放 |
|---|---|---|
| 活动生物的普通根姿态、骨骼、线条 | 常规昂贵读取 5 Hz；原生动作边界立即读取 | 用真实观察时间和有界后继点插值；不跨事件、显隐、拓扑或关卡边界混合 |
| 乌鸦已核验待机／飞离 | 原生 clip、相位、速度与检查点；稳定时跳过骨骼和外观遍历 | 按绝对时间求值原生动画；嘴层非零、过渡或未知控制器继续真实采样 |
| 青蛙地面待机 | 保留既有事件唤醒和错峰根安全检查 | 原生 FrogIdle；水中物理、抓取、跳跃不冻结 |
| 青蛙舌头短动作 | 动作边界立即记录，固定最长 0.3 秒的高频细节窗口；持续拉拽回到 5 Hz | 真实点数组插值；窗口不能由持续变化无限续期 |
| 地面活动物品 | 根与通用动画探测 5 Hz；拿取、碰撞、烹饪等实际边界立即读取 | 物品独立观察时钟插值；持有物品保留原采样频率以匹配手部 |
| EarlyWorm 已核验的 Walk／InHand／Cooked | 原生状态、相位、速度、旋转锚与首次完整外观；稳定时跳过每次形变连带的材质描述 | 只在纯视觉副本上显式求值已核验 Animator，重建形变和旋转；事件与控制器脚本不运行 |
| 静置物品和休眠生物 | 保留末态及既有事件／有限安全检查 | 原检查点或已核验待机动画，不删除回放对象 |

连续网络物理包、风力和区域通知不能无限续期。明确零风力／零区域推力被过滤，实际非零起动立即唤醒，后续使用连续观察；静置后的通知只请求受限根安全检查，不重复读取全树。燃料值使用独立 5 Hz 小字段工作集，不改几何、外观或根时间。实际碰撞、施力、拿取和状态改变仍能绕过普通周期；这避免连续通知抵消 5 Hz 限频。青蛙普通地面碰撞也不再冒充动作，真实 HopAway 仍立即唤醒。灯光、声音和粒子出生使用各自的观察／事件轨。

EarlyWorm 的主要冗余不是骨骼：原生模型没有骨骼，两项循环 blend-shape 改变却使旧路径重复保存整份 renderer／材质状态。现在将这些已知形变留给原生动画，烹饪等真实外观变化时更新完整外观。原生转场、替换控制器、未知状态或不符合核验条件的资源继续保守采样。

## 存储与跳转

Schema 25 新增物品观察时间及事件切断标记，并扩展原生动画描述符；容器保持 v4，继续读取 Schema 10–24。低频索引在后台解码时构建，使用既有有界后继页窗口，不增加生产环境场景扫描。独立页保留完整初态，回放解码缓存仍为 1 GiB 按需载入。暂停、反向、同数组时间推进和活动转静置末段均按真实时钟处理。

5 Hz 的真实物理／未知姿态只能近似采样点之间的运动，不能精确恢复未记录的任意高频变化。已核验的循环与飞离动画可由游戏资源恢复；未核验的特殊动作不凭名称猜测。有限路线结果不能代替所有关卡、多人语音和所有攻击动作验收。

## 验证口径

原生视觉验证与性能路线分开。视觉验证只在状态初始复制一次子节点与形变基线，以后的测试必须由动画运行时从旧基线重建当前姿态；每次复制当前源骨骼不能证明动画有效。比对位置、旋转、缩放、显隐和每项 blend-shape，同时核查原生源权重与材质未被回放写入。视觉探针会改变工作量，其 CPU 和体积不用于性能比较。

首轮 A 的 Worm 形变失败；加强基线后的 B 确认 Worm 三态正确，却查出此前 Raven／Frog 的 `SampleAnimation` 在本机无 Animator 副本上没有正确推进骨骼。这些失败保留，旧的“每次复制当前子节点后零误差”不能作为动作成功的证据。相同 Spider 路径一起修复：四种已核验动画现在只在纯视觉副本上使用关闭自动推进、动画事件、根运动且不含 StateMachineBehaviour 的 Animator，显式按绝对相位求值；Raven 与 Frog 的真实随机循环偏移合入记录，副本参数归零，避免重复偏移。Spider 清理 AnyState 动作输入。正常姿态刷新只清采样缓存，不重复 Rebind；首次可见或实际绑定丢失才绑定。专门契约覆盖 300 次刷新仅绑定一次和隐藏／再激活。

C／D 还揭示冷蜘蛛模板误拒绝与 Raven Fly 的默认值差异。冷模板不初始化原生 source，改在纯视觉 clone 激活绑定后完成严格参数核验；四 clip 白名单及 SMB 检查仍保留。Fly 未驱动的六处旋转采用已记录检查点中的值，避免 clone 首次绑定时捕获的待机默认值覆盖肩、腿根与喙；不读取当前 source 骨骼。回跳验收新增生物缺失检查，D 的三只缺失明确计为失败。

原生浮点 Animator 时钟与录像绝对时钟允许最多 2 ms 的有限偏差，保持现有重锚阈值，避免微小漂移反复触发全身检查点。严格 Raven 动画求值对照使用当前原生相位作为 `EvaluationClock`，仍从冻结子节点重建；原生产描述符保留在 `Clock`，另外统计并验证其相位漂移不超过 2 ms。两种证据分开报告，不将相位校正后的严格结果称为实际录像逐帧零误差。

性能对照使用相同 Level_9、固定种子、原生篝火推进和至少 100 秒雾沼稳态窗口，完整封盘后核对全部页、事件历史、端点和跨关／反向跳转。采集耗时是接受帧的采集调用耗时，不是 FPS；家族／模块百分比是压缩前 UTF-8 字段占比，不能解释成压缩后文件分摊。独立运行的物理与音频时序、加载托管堆和 GC 基线可能不同。

最终协议／存储回归 1,255 项通过，另 310 项相关项目检查通过：轨迹 35、物品回放 29、物品采集 31、物品事件 19、Worm 15、Frog 21、Raven 18、Spider 18、低频调度 7、生物事件 65、静态回放 52。新增契约连续进行 300 次同动画相位校正，全骨骼读取为 0，且跨动画、根变化和真实事件不能复用这条捷径。完整 Release 构建零警告、零错误。托管契约不模拟 Unity 图形或 FPS。

视觉路线 `sparse-visual-0830e` 正常完成，14,292 接受帧全部封盘，255 页逆序独立读取及特效历史对照通过，关卡范围违规为 0。重新从主菜单加载录像后的 13 次跨关／反向跳转均继续播放，物品、玩家关节与生物缺失为 0；独立原生动画对照和录制事件对账通过。之后修改了静置物品和乌鸦纯相位的采集去重；最终 DLL 的四种原生动画运行时及其嵌套类型，字段、方法签名与完整 IL 指令和成员／分支引用均与 E 相同。该一致性证明只覆盖动画求值器，新的采集策略另外通过契约和 G 原生路线复测，不将 E 当作最终 DLL 的完整逐帧视觉验收。

## 首轮无探针结果及重复数据定位

中间候选 F 的雾沼稳态压缩增长由 10.104 降至 6.935 MiB/min，接受帧平均采集耗时由 1.190 降至 0.548 ms。EarlyWorm 主页面条目原始速率减少 98.20%，但结果仍有额外骨骼共享块，不能将家族原始字节下降当作同等的磁盘下降。

进一步逐块归因确认：新增共享叶块中，材质 Visuals 只有 41,340 B，Lights 300 B，PoseNodes 却有 4,005,283 B，其中乌鸦占 3,932,584 B。2,416 次乌鸦更新全部保持相同根、状态、外观和 clip，只因约 2 ms 浮点相位校正重抓了44节点；锚间隔中位约1.366秒。共享目录所有 hash 唯一，问题是产生了没有必要的新姿态，128个节点模板上限又放大了反复建立完整 basis。另有9,384次物品 Sleeping→Sleeping 只有时钟变化。

后续收口保留真正静置物品的原帧、原观察时间；同动作的乌鸦相位校正只核根并更换动画描述符，复用既有节点及外观。真实动作、换 clip、外观、根或显隐变化仍建立完整检查点。本轮保持后台模板计数及8 MiB字节上限，未通过放宽相位误差或丢弃动作取得下降。组成工具也将共享材质、灯光、节点分别列为 SharedVisuals／SharedLights／SharedPoseNodes，旧报告合称 SharedAppearance 不能解释为全是材质。

海岸“生物”列的 1.27% 全是生物轨道空字段开销，没有实际生物样本：3,433 帧的 Creatures=[] 为 51,495 B、RemovedCreatures=[] 为 75,526 B，58 页的 CreatureOrder=[] 为 1,102 B，合计 128,123 B；非空次数为 0，窗口新增共享块中也没有生物块。不能据这个百分比称海岸存在持续生物姿态采集。

与上一节各区域全阶段主页面组成不同，这里只统计稳定时间，且补入独立历史和窗口内新增共享数据，所以百分比不能直接混用。雾沼的生物原始数据约 62%，一分钟与两分钟结果一致；海岸、森蕈、高山以及神殿的特效／历史是较大的原始字段来源。特效项没有逐粒子 checkpoint，包含独立分页回跳所需的特效状态／历史重复编码。

同一主页面的多类字段共用 gzip 字典，不能精确拆成压缩后的玩家／生物／物品磁盘占比。可精确区分的物理成员为混合主页面、独立特效历史、新共享块；例如独立特效历史在上述 H 稳定窗口的实际压缩字节占比依次为海岸 13.74%、森蕈 11.03%、高山 11.91%、雾沼 4.06%、神殿 16.90%，不等于表里的“特效及历史”原始总占比。
