# 0.8.23 关卡采集隔离

日期：2026-10-13。候选未安装进游戏。沿用 Schema 22、完整录像容器 v4、场景最高 30 Hz 与 1 GiB 按需页面缓存。

## 原因与边界

此前按 Unity scene 与对象活动状态管理采集；同一场景中的未来关卡仍可进入目录，部分箱子、生物与静态陷阱会提前保存完整初态，旧关停用后也有目录留在周期检查中。

原生 Campfire.Light_Rpc 调用 MapHandler.GoToSegment 后，会先递增 currentSegment，再等待迷雾收拢、实时 1 秒、关闭旧关根，下一帧才开启新关根。关卡编号不等于可见区域已经完成切换。本版按实际 segmentParent / segmentCampfire 激活状态准入；原始 main / variant 根均建轻量索引，只有当前游戏选定的根可准入。未选变体即使自身被设置为 active，也不能被当作未知全局对象放行。

## 采集策略

| 内容 | 策略 |
|---|---|
| 未激活关卡与未选地图变体 | 保留轻量原生句柄及归属，不建立骨骼、材质、灯光或完整姿态初态 |
| 实际激活的关卡 | 模块轮流建立初态，随后沿用活动采样、事件休眠与低频策略 |
| 真实交互、动作及短播放 | 已激活归属下可即时准入，事件保留实际观察时间；不能唤醒未来关 |
| 实际关闭的关卡 | 一次性退出实时目录及检查队列，释放对象的采集姿态、外观、灯光和活动绑定 |
| 携带物与动态跟随对象 | 已脱离旧根的对象重新归属；手持、装备背包内容及粘附角色的物品独立保留 |
| 篝火与迷雾 | 原生仍激活的上一处篝火独立保留；全球迷雾记录完整切关过程 |

统一门控放在重组件目录和初态读取之前，不是在文件写入后过滤。普通初态每个 Scene tick 最多准入 4 个，全局按 client 轮转，防止大量陷阱饿死箱子、环境或声音模块。准入注册回调之间另设约 1 ms 软截止；单个回调不能被抢占，后续姿态采样不属于该软截止，因此这不代表整个采集帧保证低于 1 ms。真实动作和全球迷雾存在有意的即时旁路，4 个限制只适用于普通初态。

地图根开关的少量布尔状态、全局天气与日夜仍保留，供任意页面跳转恢复场景。风暴视觉按自身地图归属独立准入，多个熔岩控制器共用同一目标时保留各自身份，不相互覆盖。

Awake / Start / OnEnable 等批量发现与真实动作分流。物品的合并通知只要包含真实动作就保留即时优先级，后续普通发现不能把它降级；单纯激活不会把全部初态变成即时工作。常态只观察少量地图根，不逐帧遍历全部未来关候选，不新增周期性全场搜索。环境首次发现增加一次 StormVisual 轻量目录登记，之后由生命周期维护。

## 历史、特效和缓存

退役只清理采集端引用，不修改已经提交的不可变快照。完整录像、滚动片段缓存和后台页面索引继续保留旧关历史。特效与声音退役仍保存已经观察到的待提交出生、末态及结束证据，分页回跳继续走原有独立恢复路径；资源模板、音频片段目录不会随旧关采集退役一起清空。

静态陷阱目录的待处理及重试队列改存 ID 与 generation，移除对象后不再通过队列持有完整 entry / snapshot；实例 ID 再用不会让旧重试唤醒新对象。对象采集的 ConditionalWeakTable 姿态与外观目录也显式释放，而非仅标记为需要重建。

## 保守例外与验证限制

网络生成物品、生物和玩家放置物经常没有地图父级。位置、最近篝火和 Biome 名称不足以可靠确定所属关卡，本版不据此硬删除这些未知对象。它们继续由原生生命周期、已有休眠和距离策略管理，避免漏掉带出的物品或跟随生物。因此不能声称所有旧关出生的根级网络对象都会在切关时强制清空。

分批初态记录的是实际观察到的状态。尚未准入的对象在短时间内发生多次未通知变化，不能凭空恢复；真实动作走即时路径，既有原生事件覆盖率和观察分辨率没有被夸大。大型关卡初态分批建立期间仍需要实机核验首次可见画面；旧关退役是切换边界的一次性工作，也需要核验该时刻的峰值。未提供本版游戏内 CPU 毫秒、FPS 或录像体积的实测降幅。
