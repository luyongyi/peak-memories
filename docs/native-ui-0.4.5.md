# 原生回忆录 0.4.5

## 范围

保留原生主菜单入口；移除录像库及加载的 `GUILayout/GUI.skin.box`。新界面直接托管于 PEAK `Zorro.UI.Modal.Modal`，使用安装游戏内的 `HeaderModalField`、`SubheaderModalField` 和 `ButtonsInputField.m_buttonPrefab`。按钮保持游戏的 UI_Blur 九宫格、棕/金色过渡和 DarumaDropOne 字体及其多语言 fallback。不附带提取出的游戏资源。

自有标题/正文根用 `ignoreLayout` 在原生 1920×1080 画布中布局，不修改共享弹窗父级尺寸。录像列表每页四条，详情独立、可滚动，录制方式切换有确认。只在列表、状态或选项改变时重建内容，不在正常录制路径创建这些 UI 对象。

原生 Modal 是全局单例，不能堆叠。窗口通过自有标题根确认所有权；已有其他弹窗时不打开，被替换后不抢回，也不关闭外来弹窗。只复制确认过不含游戏逻辑的按钮预制体，绝不复制 MainMenuMainPage / JoinRoomPage。

## 加载

`NativeReplayLoading` 调用 `LoadingScreenHandler` 内与 `LoadWithoutDisablingQueue` 相同的原生 `LoadingRoutine`。保留本次协程 handle 是为了仅停止本次流程；接口签名变化时拒绝打开回放。飞机遮罩淡出后切换离线场景，准备角色模板后释放等待，原生声音淡入结束后才设置暂停。返回主菜单同样走原生基础加载页。正常等待和取消均保留存档、成就及网络离线隔离。

原生的遮罩延迟销毁使用 scaled time，不能留到 timeScale=0 后冻结；因此仅在其音频流程完成后清理自己的遮罩。异常仅恢复自己拥有的 loading 标记与 LoadingFade 参数，不改用户主音量。

录制仍保留 0.4.4 的两种互斥模式，不更改采样字段、容器格式及私人录像。播放中的时间轴/背包调试条暂未原生化。

## 验证边界

- Release 全方案 `-warnaserror` 编译。
- ReplayContract：旧格式、连续容器、随机拖动、两种模式，以及列表分页、字段净化、无效/未完成条目。
- ReplayViewContract：原摄像机与后处理保护。
- NativeLoadingContract：原生调用契约的模拟测试，覆盖等待、取消、异常、所有权和音量恢复。不模拟真正的 Unity 协程调度器。
- 未在 Unity 中自动验证视觉或音频，不能将这些测试称为实机通过。

## 游戏内复测

1. 主菜单 → 回忆录：字体、按钮与原生弹窗一致，四条列表不碰标题；切换两类录像、翻页、刷新。
2. 点录像查看详情，滚动长名字/旧格式说明；Esc / 手柄 B 返回列表，再返回主页。鼠标/方向键/手柄能选择所有按钮。
3. 录制方式 → 选另一种 → 取消：当前模式不变；确认后切换。保存尚未结束时禁止切换。
4. 播放旧片段和完整录像：原版飞机加载，之后看到场景/人物并能听到声音，无冻结遮罩。
5. 加载中按 Esc，播放中按 Esc：原生加载结束，回到回忆录，正常游戏及旧足迹 Mod 恢复。
6. 原生断线提示出现时不被回忆录盖掉；关闭提示后可重新打开回忆录。
7. 保持已选持续录制做整局测试：仍一个完整文件，不重开分段，不同时采集 120 秒内存录像。
