# 雪堆显隐与雪球滚动尺寸：0.8.33

## 原因与修复

原生雪堆是场景中的 `FakeItem`，成功交互后隐藏自身并生成真正的雪球 `Item`。此前只录到生成的物品，未录到雪堆自身的隐藏。现在为经过原生物品数据库核验的静态 `FakeItem` 建立独立事件目录：首次记录根 TRS 与 `activeSelf`，交互、原生可见拾取／恢复和根生命周期事件只在自身显隐变化时更新。父关卡激活造成的生命周期通知不使静态子物品重新采样。仍按关卡准入和退场规则管理。

播放直接租用原场景静态模型的渲染可见性；历史状态需要显示已被原生隐藏的源时，使用不含行为、物理和网络脚本的视觉副本。不调用拾取接口，不修改 `pickedUp`，不重新激活原生游戏对象。关闭回放恢复租用的渲染状态和根 TRS。

原生雪球的 `ItemScaleSyncer` 将尺寸应用到模型及碰撞体子节点，根缩放不变；原先地面根运动观察复用了旧子节点，只有拾取事件才强制刷新。现在观察原生 `ApplyScale` 完成后的真实参数，标记轻量子节点尺寸变化。它不改变物品栏版本，不开启或续期高频动作窗口，不重新发现材质或层级；重复相同参数不通知。变化由原有地面最高 5 Hz 时钟合并读取，成功读取后才清除标记，静置后保留末态休眠，新变化重新唤醒。

原生雪山实测还发现：雪球制动完成后每帧调用 `SetKinematic(false)`，旧观察器把同值调用也记为新运动事件，持续续期活动窗口。现在普通 setter 只比较实际运动学状态前后是否改变；两个带位姿的 RPC 还精确比较刚体位置和朝向，保留运动学物体的真实传送，嵌套调用只通知一次。真正的物理包继续由各自运动观察路径捕获。相同状态重复 1800 次不产生通知、不查询位置和组件；微小连续 RPC 位移／旋转仍通知。

## 存储及跳转

Schema 27 使用原有交互轨，不增加新共享块类型。紧凑静态采集物 DTO 使用现有 kind 4 跨页共享，身份排序使用现有 kind 9；普通动态交互仍限 768，静态采集物独立限 8192。旧 schema 保留其原有限制。每个独立页包含完整目标状态，显隐按离散边界切换，无需从最早页补跑拾取。解码缓存仍为 1 GiB 按需载入。

旧录像未采集的雪堆隐藏和地面尺寸历史无法还原；旧录像继续按其实际数据播放。

## 验证

完整方案严格构建为零警告、零错误。合成／适配器回归包含：物品采集 37 项、Harmony 物品观察 33 项、静态采集物 21 项、协议及共享存储 1271 项。静态目录测试对 1000 个源连续执行 1800 次采集，无新增原生可见性或根读取；雪球测试检查两秒内重复尺寸通知合并成 10 次几何观察、静置／再唤醒及读取失败后保留变化。

共享存储新增 6 项，包含 1000 个静态源、非零录制起点、显隐与退场恢复、逆序独立页和独立特效历史；满额静态／动态混合及旧 schema 拒绝新载荷也通过。新增回放测试发现并修复第 769 个可见回退副本能通过渐进创建绕过并发上限的问题，最终明确限制 768 个，冷副本缓存另限 16。

以上契约回归在用户要求停止测试之前完成，使用受控 Unity／视觉副本适配器，不能替代游戏里的实际模型验证。自动测试的原生推动属于显式功能探针，不能据此推断正常游玩 FPS 或每分钟增长。

初始原生测试 A 的路线索引、B 的节点路径识别有误，均按失败保留，未用于功能通过结论。修正后的 C 已证明雪堆显隐、真实雪球出生及首次地面增长；它继续暴露了上述重复 setter 续期问题：等待阶段中，116 个观察样本瞬时速度为零、模型／碰撞体尺寸恒定，观察时钟仍持续推进。不能仅凭瞬时速度把对象判为静止；后续 D／E 的独立根姿态证据确认冰面上还有实际慢滑／转动。E 的采集器诊断已证明运动窗口过期、无重复边界和尺寸脏标记，此时继续记录真实位置／旋转符合要求。D 的早期增长计数范围过窄，E 的真实静置前提未成立，均保留失败，不能算静置停采通过。
